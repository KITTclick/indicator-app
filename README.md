## 🚀 Getting Started

### Prerequisites
* Node.js `>= 20.0`
* npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/KITTclick/indicator-app.git

# Navigate to project directory
cd indicator-app

# Install dependencies
npm install

# Start local terminal
npm run dev
```
